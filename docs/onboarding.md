## 👋 Bem-vindo(a) ao GameLab

> *"Nossa missão é desenvolver jogos completos, estruturados e polidos, unindo criatividade com engenharia de software de ponta."*

Se você está lendo isso, parabéns! Você agora faz parte do nosso laboratório. Este documento é o seu guia de sobrevivência para os primeiros dias.

## 🗺️ Como Funciona o Nosso Ecossistema?

Nós trabalhamos com o modelo de **Squads** (células de desenvolvimento). Atualmente, temos dois projetos ativos (Ciclo Infinito e Loot & Lunch). Você será alocado em um deles e responderá diretamente ao Coordenador e aos Líderes da sua área (Arte, Code ou Design).

Para entender a estrutura completa e quem é quem, acesse:

- [🔗 Organograma](./organograma.md)
- [🔗 Membros](./membros.md)

## 🛠️ Suas Primeiras Tarefas (Setup)

Antes de começar a colocar a mão na massa, garanta que você cumpriu este checklist:

- [ ] **Acesso ao GitHub:** Você deve ter sido convidado para a nossa Organization.
- [ ] **Acesso ao Discord:** Entre no nosso servidor e peça seu cargo ao Coordenador.
- [ ] **Ferramentas Básicas:** Instale a Engine do seu projeto, o Git e a sua IDE favorita.
- [ ] **Apresentação:** Mande um "Olá" no canal `#geral` dizendo sua função e projeto.

## 💻 Como Nós Codamos (E Trabalhamos)

Tratamos nossos jogos como produtos profissionais. Portanto:

1. **Nunca comite na branch `main`:** Use o fluxo de branches (`feature/nome-da-feature`, `fix/nome-do-bug`).
2. **Abra Pull Requests:** Seu código/arte precisa ser revisado pelo seu Líder antes de ir para o jogo final. Leia nossas regras de Pull Request no repositório do jogo.
3. **Mantenha a Comunicação:** Travou em algo? Peça ajuda no Discord. O laboratório é um espaço de aprendizado conjunto.

## 📚 Leituras Obrigatórias do Seu Projeto

Vá até o repositório do projeto em que você foi alocado e leia os dois documentos sagrados:

- **GDD (Game Design Document):** Para entender o que estamos construindo.
- **Tech Stack / Art Bible:** Para entender as restrições técnicas e visuais.

Bem-vindo a bordo! 🚀
