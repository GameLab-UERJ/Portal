## Guia de uso rapido

Voltar para:

- [Kit de Templates e Workflows](../kit-templates-workflows.md)

Este guia mostra como aplicar os arquivos de template em um repositorio de jogo.

Passo a passo recomendado:

1. Copiar templates de documento para a pasta docs do repositorio do jogo.
2. Copiar templates de PR e Issue para .github no repositorio do jogo.
3. Copiar workflows para .github/workflows e ajustar nomes de branch quando necessario.
4. Abrir PR de infra com checklist de adocao para validacao da lideranca.

Checklist minimo de adocao:

- [ ] Template de GDD disponivel para a equipe.
- [ ] PR template ativo no repositorio.
- [ ] Issue templates de bug e feature ativos.
- [ ] Workflow de PR check ativo e passando.
- [ ] Workflow de release ativo e documentado.
